# 🎥 AI Video Interview Platform

Асинхронное техническое видеоинтервью с объяснимой ИИ-оценкой. Заменяет
синхронную часовую встречу с внешним экспертом:

```
вакансия + резюме → вопросы → ссылка кандидату → видеоинтервью →
транскрипция → адаптивные уточнения → ИИ-заключение с доказательствами →
review рекрутера → финальное решение нанимающего менеджера
```

Главный фокус — **качество и объяснимость оценки**: каждый существенный вывод
подкреплён дословной цитатой из ответа кандидата.

## Быстрый старт

### Docker
```bash
cp .env.example .env      # вписать ключи (см. ниже); без них — mock-режим
docker compose up --build
```

### Локально
```bash
python -m venv .venv && source .venv/bin/activate   # Python 3.12
pip install -r requirements.txt
cp .env.example .env
python main.py
```

Откройте `https://localhost:8000/login`. `main.py` — единственная точка запуска.

При первом запуске автоматически создаётся временный self-signed сертификат в
`.certs/`; браузер один раз предупредит о нём — это нормально для dev. Для
реального домена задайте `TLS_CERT_FILE` и `TLS_KEY_FILE` (вместе), опционально
`TLS_HOST`.

Без ключей приложение проходимо в mock-режиме, но оценка ненастоящая — для демо
нужны ключи LLM и ASR.

## Ключи и модели (`.env`)

| переменная | назначение |
|---|---|
| `LLM_API_KEY`, `LLM_BASE_URL` | OpenAI-совместимый LLM: разбор вакансии, генерация вопросов, итоговое заключение |
| `LLM_MODEL` | основная модель (разбор, финальный отчёт) |
| `LLM_MODEL_FAST` | быстрая модель для шагов во время интервью (оценка ответа, решение об уточнении, очистка расшифровки) |
| `DEEPGRAM_API_KEY` | ASR (Deepgram `nova-3`), русская речь с keyterm-подсказками из вопроса |
| `TTS_API_KEY`, `TTS_BASE_URL` | OpenAI-совместимый синтез речи (`/audio/speech`); задаётся отдельно от LLM |
| `TTS_VOICE` | голос: `serena`, `vivian`, `dylan`, … |
| `TTS_INSTRUCTIONS` | эмоция/стиль свободным текстом, напр. «спокойно, доброжелательно» |

Все ключи опциональны и деградируют мягко: нет TTS — вопрос читается голосом
браузера; нет ASR/LLM — заглушки.

## Роли

- **Рекрутер (HR)** — создаёт вакансию (разбор описания/резюме, автогенерация
  вопросов), ведёт кандидатов по воронке, выдаёт одноразовые ссылки, смотрит
  карточку результата.
- **Кандидат** — переходит по персональной ссылке, даёт согласие на запись,
  проверяет камеру/микрофон и последовательно отвечает.
- **Нанимающий менеджер** — видит только переданного ему кандидата и принимает
  финальное решение.

### Авторизация
Первый аккаунт при пустой базе становится HR-владельцем воркспейса. Дальше
сотрудники добавляются только по одноразовой invite-ссылке (48 ч, роль зашита в
ссылку). Мастер-ключей нет. Сессия — `Secure + HttpOnly + SameSite=Lax` cookie.

## Сценарий кандидата

- **Согласие на запись** — блокирующий экран до старта, с версионированием.
- **Проверка оборудования** — камера, микрофон, уровень звука.
- Вопрос **показывается и озвучивается** (`TTS_VOICE`).
- Ответ пишется по одному, с таймером; статусы обработки видны явно
  (записано → распознаём → готово → анализируем).
- Кандидат **правит транскрипт** перед подтверждением или жмёт **«Ответить
  заново»**.
- **Адаптивные уточнения** — до 2 на корневой вопрос (лимит на бэкенде).
- **Возобновление** прерванного интервью с сервера (обрыв сети/вкладки).
  Завершённое интервью повторно не открывается.
- **«Закончить досрочно»** — сохраняются ответы на пройденные вопросы; балл
  считается по отвеченному, непройденное помечается «не проверено».
- **Срок действия ссылки** (14 дней), после — понятный экран.

### Прокторинг
Браузерные сигналы (уход со вкладки, буфер, fullscreen, разрывы сети/камеры) и
локальный MediaPipe (нет лица, второе лицо, отвод головы/взгляда; кадры на сервер
не уходят). Это evidence для ручной проверки — **на технический балл не влияет** и
показывается в карточке отдельным блоком.

## Карточка результата

Рекомендация и балл с уверенностью модели; покрытие обязательных требований
(подтверждено / частично / риск / не проверялось); сильные стороны, риски и зоны
роста — с цитатами; ответы кандидата с оценками, транскриптом и видеофрагментом;
цепочки адаптивных уточнений; полная видеозапись; блок прокторинга.

## Архитектура

- **FastAPI / Python 3.12**, **SQLite** (аддитивные миграции без разрушающих
  ALTER — см. `migrations.py`).
- **Backend**: `main.py` собирает legacy-флоу (`legacy_main.py`) с
  канонизированными роутерами (`adaptive_routes`, `adaptive_submit_routes`,
  `scoring_routes`, `question_bank_routes`, `workspace_routes`) под gateway
  авторизации (`app.py`).
- **Frontend рекрутера/менеджера** — React SPA (`frontend/`), собирается в
  `static/app`, отдаётся на `/app`. Страница кандидата — server-rendered
  (`templates/interview.html`).
- **Медиа**: браузерный `MediaRecorder` → `ffmpeg/ffprobe` нормализация →
  per-answer видеоклипы по `start_ms/end_ms`.

### Сборка фронтенда
```bash
cd frontend
npm ci
npm run build      # результат кладётся в ../static/app
```
Собранный бандл коммитится в репозиторий, поэтому для запуска backend Node не
нужен — только если меняете сам фронтенд.
