# Video Interview MVP

Сервис асинхронного видеоинтервью с ИИ-анализом ответов кандидатов.

## Архитектура

```
┌─────────────┐     ┌──────────────┐     ┌─────────────┐
│    HR/Менеджер │────▶│   FastAPI   │────▶│  PostgreSQL │
└─────────────┘     │   Backend   │     │  (SQLite)   │
                    └──────────────┘     └─────────────┘
                           │
                           ▼
                    ┌──────────────┐
                    │   LLM API    │ (OpenRouter/Qwen)
                    │   ASR API    │ (DeepGram)
                    │   TTS        │ (Edge-TTS)
                    └──────────────┘
```

## Компоненты

1. **Backend** (FastAPI)
   - REST API для управления вакансиями и интервью
   - Интеграция с LLM для анализа ответов
   - Генерация итоговых отчетов

2. **Frontend** (HTML + JS)
   - Личный кабинет HR/менеджера
   - Страница прохождения интервью кандидатом
   - Просмотр результатов

3. **AI Сервисы**
   - **LLM** (Qwen/OpenRouter) — анализ ответов, генерация отчетов
   - **ASR** (DeepGram) — транскрибация аудио
   - **TTS** (Edge-TTS) — озвучивание вопросов

## Установка

```bash
cd video_interview_mvp

# Установка зависимостей
pip install -r requirements.txt

# Запуск сервера
python main.py

```


## API Endpoints

### Auth
- `POST /api/auth/register` — регистрация пользователя
- `POST /api/auth/login` — вход

### Vacancies
- `GET /api/vacancies` — список вакансий
- `POST /api/vacancies` — создание вакансии (с авто-подбором вопросов)
- `GET /api/vacancies/{id}` — детали вакансии

### Interviews
- `POST /api/interviews/create` — создание сессии интервью
- `GET /api/interviews/{token}` — информация о сессии
- `POST /api/interviews/{token}/start` — начало интервью
- `POST /api/interviews/submit-answer` — отправка ответа
- `POST /api/interviews/{id}/complete` — завершение интервью

### Reports
- `GET /api/reports/{session_id}` — получение отчета

## Пользовательский сценарий

### Для HR:
1. Регистрация/вход в систему
2. Создание вакансии (загрузка описания и требований)
3. Система автоматически подбирает вопросы по тегам
4. HR аппрувит финальный список вопросов
5. Создание ссылки на интервью для кандидата
6. Отправка ссылки кандидату
7. Получение отчета с ИИ-анализом

### Для Кандидата:
1. Переход по персональной ссылке
2. Разрешение доступа к камере/микрофону
3. Последовательные вопросы (текст + аудио)
4. Запись видео-ответа (2 минуты на вопрос)
5. Проверка транскрипции
6. Завершение интервью

### Для Нанимающего Менеджера:
1. Получение ссылки на отчет
2. Просмотр общей оценки и рекомендации
3. Детальный разбор ответов по вопросам
4. Принятие решения о дальнейшем движении

## Структура отчета

Итоговый отчет включает:
- **Общая оценка** (0-10)
- **Рекомендация**: подходит / не подходит / требуется доп. проверка
- **Сильные стороны** кандидата
- **Зоны роста**
- **Выявленные навыки**
- **Вопросы для дополнительной проверки**
- **Потенциальные риски**
- **Детали по каждому вопросу** (транскрипт, оценка, анализ)

## Банк вопросов

Вопросы хранятся в `data/questions.json`. Каждый вопрос содержит:
- Текст вопроса
- Теги (для подбора по вакансии)
- Компетенция
- Эталонный ответ
- Must-have критерии
- Nice-to-have критерии
- Red flags

## Целевые метрики MVP

- ≥80% совпадений решений ИИ с экспертом
- Корректная транскрибация ответов
- Структурированное заключение по кандидату
- Полный цикл без участия технического эксперта
