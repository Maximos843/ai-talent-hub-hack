# Video Interview MVP - Docker Quick Start

## Быстрый старт для тестирования

### Вариант 1: Запуск без API ключей (демо-режим)

В этом режиме система работает с моковыми ответами для LLM и ASR. Идеально для демонстрации интерфейса и потока.

```bash
# Просто запустите контейнер
docker-compose up --build

# Откройте браузер: http://localhost:8000
```

**Что работает в демо-режиме:**
- ✅ Создание вакансий
- ✅ Подбор вопросов по тегам
- ✅ Генерация ссылок для кандидатов
- ✅ Интерфейс прохождения интервью
- ✅ Запись видео/аудио
- ❌ TTS озвучка вопросов (работает локально через Edge-TTS)
- ❌ ASR транскрибация (возвращает заглушку)
- ❌ LLM анализ ответов (возвращает预设ленные оценки)

### Вариант 2: Запуск с реальными API

1. Получите API ключи:
   - **LLM**: [OpenRouter](https://openrouter.ai/) или используйте Qwen напрямую
   - **ASR**: [DeepGram](https://deepgram.com/)

2. Создайте файл `.env` в корне проекта:
```bash
cp .env.example .env
```

3. Отредактируйте `.env`, добавив ваши ключи:
```env
LLM_API_KEY=your_openrouter_key_here
DEEPGRAM_API_KEY=your_deepgram_key_here
```

4. Запустите с ключами:
```bash
docker-compose --env-file .env up --build
```

**Что работает с ключами:**
- ✅ Все функции из демо-режима
- ✅ Реальная TTS озвучка вопросов (Edge-TTS, бесплатно)
- ✅ Реальная ASR транскрибация ответов (DeepGram)
- ✅ Реальный LLM анализ ответов и генерация отчетов

## Тестовый сценарий

### 1. Регистрация HR
- Откройте http://localhost:8000/login
- Зарегистрируйтесь как HR:
  - Username: `hr_test`
  - Password: `password123`
  - Role: `hr`
  - Full Name: `Тестовый HR`

### 2. Создание вакансии
- В дашборде нажмите "Создать вакансию"
- Заполните:
  - Title: `Python Backend Developer`
  - Description: `Разработка backend-сервисов на Python, работа с Docker, CI/CD`
  - Requirements: `Python 3+, Docker, PostgreSQL, опыт работы с микросервисами`
  - Grade: `middle`
- Система автоматически подберет 10-15 вопросов по тегам

### 3. Аппрув вопросов
- Просмотрите предложенные вопросы
- При необходимости удалите лишние или добавьте свои
- Нажмите "Аппрувить вопросы"

### 4. Создание интервью для кандидата
- В карточке вакансии нажмите "Создать интервью"
- Введите имя кандидата: `Иван Иванов`
- Скопируйте ссылку вида: `/interview/{uuid-token}`

### 5. Прохождение интервью (роль кандидата)
- Откройте скопированную ссылку в новой вкладке/браузере
- Разрешите доступ к камере и микрофону
- Для каждого вопроса:
  - Прослушайте озвученный вопрос (TTS)
  - Запишите видео-ответ (2 минуты)
  - Проверьте транскрипт (можно отредактировать)
  - Подтвердите ответ
- После последнего вопроса интервью завершится

### 6. Просмотр результатов (роль HR)
- Вернитесь в дашборд HR
- Нажмите на вакансию → увидите список кандидатов
- Нажмите на кандидата → откроется отчет с:
  - Видео-ответами по каждому вопросу
  - Транскриптами
  - Оценками (0-10) по каждому вопросу
  - Итоговой рекомендацией: "подходит"/"не подходит"/"требуется дополнительная проверка"
  - Выявленными навыками и зонами роста

### 7. Доступ для нанимающего менеджера
- HR может отправить ссылку на отчет нанимающему менеджеру
- Менеджер видит только конкретного кандидата (без доступа ко всем вакансиям)


## Управление контейнером

```bash
# Запуск
docker-compose up -d

# Просмотр логов
docker-compose logs -f

# Остановка
docker-compose down

# Пересборка
docker-compose up --build

# Сброс базы данных (удалит все данные!)
rm video_interview.db && docker-compose up --build
```

## Примечания

- **База данных**: SQLite хранится в `video_interview.db` (сохраняется между перезапусками)
- **Видео файлы**: Сохраняются в папке `uploads/` (также сохраняются)
- **TTS**: Edge-TTS не требует API ключа, работает бесплатно через Azure
- **ASR**: DeepGram дает 2 часа бесплатной транскрибации при регистрации
- **LLM**: OpenRouter дает бесплатный стартовый баланс для тестирования

## Troubleshooting

**Ошибка "Port already in use"**:
```bash
# Измените порт в docker-compose.yml
ports:
  - "8001:8000"  # вместо 8000:8000
```

**Видео не записывается**:
- Убедитесь, что браузер имеет доступ к камере/микрофону
- Проверьте, что используется HTTPS (для localhost HTTP работает)

**LLM не отвечает**:
- Проверьте API ключ в `.env`
- Убедитесь, что на балансе OpenRouter есть средства
- В демо-режиме работают моковые ответы
