# ai-talent-hub-hack

Платформа асинхронного технического видеоинтервью с объяснимой ИИ-оценкой
кандидатов.

Приложение — в [`video_interview_mvp/`](video_interview_mvp/README.md). Там
описаны запуск, ключи, роли и архитектура.

```bash
cd video_interview_mvp
cp .env.example .env
python main.py            # https://localhost:8000/login
```
